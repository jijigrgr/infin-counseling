# 🐱 김지현 선생님 상담 예약 - Google Apps Script 버전

학생 개인정보가 외부 서버에 안 가고 **선생님 본인 Google Drive 안**에만 저장되는 버전이에요.

---

## 📋 설치 순서

### 1단계: 구글 시트 만들기
1. https://sheets.google.com 접속
2. **빈 시트 + 새로 만들기**
3. 시트 이름을 "**상담 예약**" 등 알아보기 쉽게 변경
4. 브라우저 주소창에서 **시트 ID** 복사 (URL 가운데 긴 문자열)
   ```
   https://docs.google.com/spreadsheets/d/이부분이ID/edit
   ```

---

### 2단계: Apps Script 열기
시트에서 메뉴 → **확장 프로그램** → **Apps Script** 클릭

---

### 3단계: 파일 4개 만들기

Apps Script 에디터 왼쪽 **파일** 옆 **+ 버튼**으로 다음 파일들을 만들어요.

#### ① `Code.gs` (이미 있음 — 내용만 교체)
- 왼쪽 파일 목록의 `Code.gs` 클릭
- 기존 내용 전부 지우고 → 본 폴더의 `Code.gs` 내용 **복사 붙여넣기**
- **맨 위 `SHEET_ID` 값을 본인 시트 ID 로 바꾸기** ⚠️

#### ② `Index.html`
- **+ → HTML** → 이름: `Index` (확장자 제외)
- 본 폴더의 `Index.html` 내용 복사 붙여넣기

#### ③ `Admin.html`
- **+ → HTML** → 이름: `Admin`
- 본 폴더의 `Admin.html` 내용 복사 붙여넣기

#### ④ `Style.html`
- **+ → HTML** → 이름: `Style`
- 본 폴더의 `Style.html` 내용 복사 붙여넣기

전부 저장 (💾 아이콘 또는 Ctrl+S)

---

### 4단계: 관리자 비밀번호 설정
1. Apps Script 에디터 상단의 **함수 선택** 드롭다운에서 `setAdminPassword` 선택
2. ▶ **실행** 버튼 클릭
3. 처음이라면 **권한 요청** 나옴 → 본인 계정으로 승인
4. 시트로 돌아가서 메뉴 **🛠 상담 예약 설정 → 관리자 비밀번호 설정**
5. 원하는 비밀번호 입력

> ⚠️ 시트를 처음 열 때 메뉴가 안 보이면 새로고침 한 번 하세요.

---

### 5단계: 웹앱으로 배포
1. Apps Script 에디터 우측 상단 **배포** → **새 배포**
2. 톱니바퀴 → **웹 앱** 선택
3. 설정:
   - **설명**: `상담 예약` (자유)
   - **다음 사용자 인증 정보로 실행**: **나** ⚠️ (꼭 "나")
   - **액세스 권한**: **모든 사용자** (학생들이 접근 가능하게)
4. **배포** 클릭
5. **권한 검토** → 본인 계정 → **고급 → 안전하지 않음(상세) → 이동** → 허용
6. **웹 앱 URL** 복사 (이게 학생용 주소!)

---

## 🔗 사용 방법

### 학생용 주소
배포 후 받은 URL 그대로 학생에게 공유

### 선생님(관리자) 주소
학생용 URL 뒤에 **`?page=admin`** 붙이기

예시:
```
학생용:    https://script.google.com/macros/s/AKfyc.../exec
관리자용:  https://script.google.com/macros/s/AKfyc.../exec?page=admin
```

관리자 페이지에서 4단계에서 설정한 비밀번호 입력하고 로그인.

## 📊 데이터는 어디에?

전부 **본인 구글 시트** 안에 있어요:
- **Reservations** 탭: 학생 예약 (이름, 반, 날짜, 시간, 고민)
- **Announcements** 탭: 공지사항

시트 공유 권한은 **본인만 보기**로 두세요. (Apps Script 가 알아서 읽고 씀)

---

## 🔄 코드 수정하고 싶을 때

1. Apps Script 에디터에서 코드 수정 → 저장
2. **배포 → 배포 관리 → 연필 아이콘** → **버전: 새 버전** → **배포**
3. URL 은 그대로 (다시 공유 안 해도 됨)

## ❓ 자주 묻는 것들

**Q. 학생이 로그인해야 하나요?**
A. 아니요. URL 만 알면 누구나 예약 가능. 다만 관리자 페이지는 비밀번호 필요.

**Q. 예약 시간 규칙은?**
A. 코드에 박혀있음 (월~금 07:30 / 화·수·금 16:00, 16:30). 바꾸려면 `Code.gs` 의 `isValidSlot` 함수 수정.

**Q. 비밀번호 잊었을 때?**
A. Apps Script → 프로젝트 설정 (톱니바퀴) → 스크립트 속성 → `ADMIN_PASSWORD` 값 확인/수정.

**Q. 엑셀 다운로드 안 돼요**
A. CSV 로 다운로드돼요. 엑셀로 열면 그대로 표 형식 보여요. (Apps Script 에서 .xlsx 만들기는 복잡해서 CSV 로 했어요)

**Q. 학생이 제출하면 선생님께 이메일 알림 줄 수 있나요?**
A. 가능. `createReservation` 함수 끝에 `MailApp.sendEmail(...)` 추가하면 돼요. 필요하면 말씀해주세요.

## 🆘 문제 생기면

Apps Script 에디터에서 **실행** 탭 들어가서 빨간 에러 메시지 확인하세요. 자주 발생하는 것들:

- `SHEET_ID 가 잘못됨` → 1단계 시트 ID 다시 확인
- `권한 없음` → 5단계 권한 승인 안 됨
- `메뉴 안 보임` → 시트 새로고침 (F5)

도움 필요하면 에러 메시지 그대로 보내주세요!
